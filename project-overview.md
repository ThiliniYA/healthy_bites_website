# Healthy Bites – Project Overview

Healthy Bites is a small website I originally created during my diploma to practise basic coding.  
Later, I used this same website to build my QA skills by doing manual testing and beginner‑level automation.

This project shows how I test a simple website from start to finish.

---

## 📌 What This Project Includes

- A static website with three pages  
- Manual testing (test plan, test cases, bug reports, summary)  
- Real defects found during testing  
- Beginner‑friendly automation (Selenium C#) – coming soon  
- Clean folder structure  
- Screenshots and documentation  

---

## 🖥️ Website Pages

The website contains:

- **Home page (index.html)** – general content and links  
- **Recipes page (recipes.html)** – recipe cards and images  
- **Register page (register.html)** – simple form for user details  

These pages gave me enough functionality to practise UI testing, navigation testing, and form validation.

---

## 🧪 Manual Testing

I performed manual testing to check:

- page loading  
- navigation  
- layout and styling  
- form behaviour  
- positive and negative scenarios  
- cross‑browser behaviour  

All manual testing documents are inside the **manual-testing** folder.

---

## 🐞 Bugs Found

I found real issues during testing, including:

- invalid email accepted  
- broken YouTube link  
- weak password validation  
- layout alignment issues  

These bugs are documented with steps, expected results, and actual results.

---

## 🤖 Automation (Coming Soon)

I will add simple Selenium C# tests to show:

- basic automation skills  
- page object model  
- clean test structure  
- easy‑to‑run tests  

This will help me demonstrate that I understand automation basics and can learn new tools quickly.

## 🎯 Why This Project Matters

Healthy Bites is important in my QA journey because:
